# Line and Polygon Clipping Algorithms

Implements three classic clipping algorithms in pure Python:
- Cohen–Sutherland line clipping
- Liang–Barsky line clipping
- Sutherland–Hodgman polygon clipping (also includes rectangle helper)

## Run the demo

```bash
python clipping.py
```

The demo prints sample clipping results for both line algorithms and shows polygon clipping against an axis-aligned rectangle. No external dependencies are required.
